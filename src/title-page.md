# The Compact Programming Language

_Compile, Verify, Execute._

This book teaches you how to write smart contracts in **Compact**, the smart
contract language of the **Midnight network**.

This version of the text assumes you are on the Midnight mainnet toolchain.
See [Chapter 1 - Getting Started][ch01] for instructions on installing the
Compact toolchain.
