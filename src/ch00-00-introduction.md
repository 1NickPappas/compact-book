# Introduction

This book is a comprehensive, practical guide to the Compact smart contract
language.

## Who Should Read This Book

- Developers who want to build smart contracts for the Midnight network.
- Solidity or other smart-contract developers looking to move to Compact.
- Anyone who enjoys working with formally verified, low-level languages.

## What You'll Need

- A basic understanding of programming (variables, functions, control flow).
- The Compact toolchain installed (see the next chapter).

## How to Read This Book

Chapters are roughly ordered from beginner to advanced. Chapter 2 walks you
through writing your first contract end to end; later chapters assume you did
that work.

The code in this book is tested where possible, so if a snippet looks
incorrect, it almost certainly is: the toolchain will tell you.
